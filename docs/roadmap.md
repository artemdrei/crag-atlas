# Roadmap

Порядок реалізації, узгоджений з дизайном (Design canvas). Кожен пункт —
окремий вертикальний зріз: статичний UI (common/desktop/mobile) → підключення
до `apps/api` (поки на статичному JSON, не Supabase — див.
`docs/domain.md`) → готово, перехід до наступного.

Дизайн-система: підхід перенесений з badNerd (структура токенів
palette/typography), кольори — свій акцент під клаймінг-тему, не 1:1 копія.

1. Дизайн-система (токени, кольори, типографіка)
2. Лендінг / вибір регіону ("Куди лізеш?")
3. Сторінка регіону (список секторів)
4. Сторінка сектора (топо + список маршрутів)
5. Сторінка маршруту (бета, відео, коментарі, мої пролази)
6. Відмітити пролаз (форма Tick)
7. Логбук
8. Профіль (дизайн у стилі badNerd)
9. Налаштування профілю
10. Гостьовий режим (без акаунта)
11. Адмін-редактор (сектор/маршрут, чернетка/публікація)
12. Карта (мобайл, низький пріоритет)

Поза скоупом зараз: Garmin-інтеграція — окрема історія, не чіпаємо.

Кожен пункт (крім #1) реалізується для десктопу і мобайлу окремо
(`common/desktop/mobile` — див. `CLAUDE.md`).
